# Likha — UI/UX Improvement & Visual Direction

## Overall Design Direction

Redesign Likha with a **premium, editorial, and highly visual interface** inspired by the design principles of **Apple** and the discovery experience of **Pinterest**, while maintaining a distinct **Filipino creative identity**.

The goal is to make Likha feel like a **premium creative platform**, not a generic marketplace or social media app.

The interface should prioritize:

* Clean, spacious layouts
* Strong visual hierarchy
* High-quality creator content
* Minimal UI chrome
* Smooth, subtle animations
* Rounded surfaces and refined components
* Large, immersive imagery
* Elegant typography
* Intuitive interactions

Think:

> **Apple's refinement + Pinterest's visual discovery + Filipino creativity**

---

## 01. Apple-Inspired Premium UI

Adopt Apple's design philosophy rather than directly copying Apple's interface.

### Design principles

* Generous whitespace and breathing room
* Minimal visual clutter
* Clear hierarchy between primary and secondary actions
* Large, high-quality imagery
* Refined typography
* Soft rounded corners
* Subtle shadows and depth
* Smooth transitions and micro-interactions
* Consistent spacing and component sizing
* Content should feel more important than the interface itself

Avoid excessive borders, gradients, heavy shadows, and unnecessary UI elements.

The interface should feel **calm, polished, and intentional**.

---

## 02. Pinterest-Inspired Discovery

The Inspiration experience should feel highly visual and naturally addictive to browse.

Use a **masonry-style feed** where appropriate, allowing creator projects and artwork to retain their natural aspect ratios instead of forcing everything into identical cards.

Content should be the hero.

Each card should have minimal information initially:

**Artwork / Project**

Creator avatar · Creator name

Optional:

* Category
* Location
* Appreciation count

Additional information should appear when the user interacts with the content.

### Discovery should feel effortless

Users should be able to:

**Scroll → Discover → Open → Appreciate → Save → Follow → Shop**

without being overwhelmed by buttons and metadata.

---

## 03. Filipino Creative Identity

The Filipino identity should be integrated subtly into the visual system.

Avoid making the app overly literal with Philippine flags, national colors, or stereotypical tropical graphics.

Instead, incorporate contemporary Filipino influences through:

* Warm cream backgrounds
* Likha Yellow accents
* Subtle banig-inspired geometry
* Handcrafted textures
* Organic shapes
* Editorial layouts
* Hand-drawn details
* Filipino creative photography and illustrations
* Regional discovery and cultural collections

The visual language should feel:

> **Modern Filipino craftsmanship.**

# 05. Floating Bottom Navigation

Replace the traditional full-width bottom navigation with a **floating, pill-shaped navigation bar**.

The navigation should:

* Float above the bottom edge
* Have large rounded ends
* Have a subtle shadow or elevation
* Use a slightly translucent or solid premium surface
* Have comfortable spacing around the navigation
* Respect iOS and Android safe areas

Example structure:

**Home · Discover · + · Activity · Profile**

The navigation should feel like a **floating control surface**, rather than a fixed application footer.

### Center Create Button

The center of the navigation should contain a prominent **`+` Create button**.

The button should be visually distinct from the other navigation items.

For example:

**Home | Discover | `＋` | Activity | Profile**

The `+` button represents the core action of Likha:

> **Create something.**

Tapping it should open a beautiful creation menu with options such as:

* **Post a Project**
* **Share a WIP**
* **Add a Product**
* **Open for Commissions**

The creation menu should use a smooth bottom-sheet animation rather than immediately navigating to another screen.

---

# 06. Creation Experience

The `+` button should make posting extremely accessible.

The user should never have to navigate through multiple menus just to create something.

### Quick Create

```text
              Create

      ┌─────────┐  ┌─────────┐
      │    ✦    │  │   🛍    │
      │ Project  │  │ Product │
      └─────────┘  └─────────┘

      ┌─────────┐  ┌─────────┐
      │    ◌    │  │    ✎    │
      │   WIP   │  │Commission│
      └─────────┘  └─────────┘
```

Keep this experience visually lightweight and fast.

---

# 07. Cards & Surfaces

Cards should feel **soft and premium**, not like traditional dashboard cards.

Prefer:

* Large corner radii
* Minimal borders
* Subtle elevation
* Generous internal spacing
* High-quality imagery
* Clear typography

Avoid putting every piece of content inside a separate bordered container.

Use **open layouts** where possible.

---

# 08. Creator Profiles

Creator profiles should feel like **personal creative portfolios** rather than standard social media profiles.

Prioritize:

1. Creator identity
2. Featured work
3. Portfolio
4. Shop
5. About
6. Reviews / credibility

Use large visual previews and editorial-style project layouts.

The profile should communicate:

> **"This is someone's creative space."**

rather than:

> **"This is someone's social media account."**

---

# 09. Marketplace

The Shop experience should remain visually connected to the portfolio.

A project should naturally lead into:

**View project → See the work → Shop the work → Buy**

Products should use large imagery, clean pricing, minimal metadata, and clear purchase actions.

Avoid making the marketplace feel like a traditional e-commerce website.

It should feel like **shopping through a creative gallery**.

---

# 10. Motion & Interaction

Introduce subtle motion throughout the application.

Examples:

* Smooth page transitions
* Image scaling when opening projects
* Soft button press animations
* Floating navigation movement
* Bottom-sheet creation menu
* Like/appreciation animations
* Save-to-collection animation
* Skeleton loading states
* Smooth tab transitions

Animations should feel **natural and premium**, never flashy or distracting.

---

# 11. Overall UX Goal

Every screen should answer one question:

> **What is the most important thing the user should see or do here?**

Reduce unnecessary UI elements and prioritize content.

Likha should feel:

**Premium like Apple.**
**Visual like Pinterest.**
**Creative like Behance.**
**Commercial like Etsy.**
**Filipino at its core.**

The final experience should feel like a **digital creative gallery built for Filipino creators**, where discovering, showcasing, and buying creative work all feel like part of the same seamless experience.
